# Data availability and responsible reuse

This package does not redistribute raw Reddit comment text, post/comment IDs, usernames, parent-comment text, manually coded rows, API responses, or model-prediction rows. Usernames were not collected during this study. The omission is deliberate: availability and redistribution conditions for archived Reddit content can vary, and the source text may contain personal or sensitive information.

## Source and reconstruction

Candidate communities were located through Reddit Community Search, using SIC-informed occupation terms. Historical post/comment retrieval used Arctic Shift where available. A reproducing researcher must independently obtain data in a manner consistent with applicable platform terms, institutional ethics requirements, and local law, then apply the included code and documented inclusion rules.

## What is included

- code and frozen parameter settings;
- aggregate corpus composition, topic-size, model, lexical, and validation results;
- final publication figures and source aggregates;
- researcher-led topic mappings without comment text.

## What is excluded

- raw/derived comment-level corpus and IDs;
- raw human annotations and prediction-level outputs;
- cached embeddings and fitted BERTopic binaries;
- credentials, tokens, browser profiles, and API logs containing source text.

The study period is March 2023 to January 2026 inclusive. Post publication date defined eligibility. Comments posted after January 2026 were retained only when they belonged to an eligible post thread, as documented in the final collection protocol.
