# Capstone 2026: Trust in AI

Reproducibility materials for the MSc Applied Social Data Science Capstone Project:

**Occupational Responses to Generative AI: A Cross-Industry Analysis of Themes, Attitudes and Trust Boundaries on Reddit**

Candidate number: 66846

## Repository contents

- `reproducibility_package/` — code, aggregate validation outputs, robustness analyses, and supporting materials used in the dissertation.
- `prompt_v2.txt` — frozen GPT-assisted annotation prompt used for production classification and model comparison.

## Data availability

Raw Reddit posts and comments are not redistributed in accordance with the approved research ethics protocol. The repository contains non-sensitive materials required to reproduce the analytical workflow and reported validation results.

## Reproducibility

See the files and documentation within `reproducibility_package/` for the analysis pipeline and supporting outputs.
